# radvis
3D JS/HTML Antenna simulation suite

## Features
Allows you to add multiple elements to an antenna and predict the outcome, both in terms of SWR and radiation pattern.

3D visualization is updated the instant you make any significant changes, and provides you with some feedback on the given results.

Rotate the antenna in any direction to see how it behaves vertically, horizontally, upside-down, etc.

Adjust the height-above-ground to see how the radiation pattern change.

## What?
A simple tool written in JS/HTML to visualize the radiation pattern, as well as provide an SWR estimate on your new (or existing) antenna design.

## Why?
Because it's always neat to have a portable tool available, no matter where you are. No installs required, no platform restrictions, no heavy system requirements.
