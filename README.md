# radvis
3D Antenna simulation suite written in HTML/Javascript

## What?
This is a simpl tool for visualizing and simulating the radiation pattern of an antenna, as well as providing efficiency estimates and SWR plots.

## Why?
Because it's always neat to have a portable tool available, no matter where you are. No installs required, no platform restrictions, no heavy system requirements.

## Features
- 3D visualization of radiation pattern
- Can load preset antennas as starting point
- Allows multiple elements, both active and parasitic
- Outcome prediction (great match, workable, bad match)
- Calculates feedpoint impedance, peak gain, and take-off angle
- Plots SWR, pattern cuts
- Antenna project can be loaded/saved
- Adjustable AGL and feedpoint position
