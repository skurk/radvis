# radvis
3D Antenna simulation suite written in HTML/Javascript
A simple tool for visualizing and simulating the radiation pattern of an antenna, as well as providing efficiency estimates and SWR plots.

## Screenshot
![Screenshot](https://github.com/skurk/radvis/blob/main/radvis-screenshot.png?raw=true)

## What?
- 3D visualization of radiation pattern
- Can load preset antennas as starting point
- Allows multiple elements, both active and parasitic
- Outcome prediction (great/bad match, workable)
- Calculates feedpoint impedance, peak gain, and take-off angle
- Plots SWR, pattern cuts
- Antenna project can be loaded/saved
- Adjustable AGL and feedpoint position

## How?
This will basically run on any computer or platform having a modern Chromium-compatible web browser (Chrome, Brave, Firefox, Safari, Edge, etc)
No installs, no platform restrictions, no top-end system requirements.

## Why?
Because it's always neat to have a portable tool available, no matter where you are.
